# V1.1 Tool Calling Loop

## 目标
把 V1.0 的模型网关从“单次回答”升级为真正的 Agent Loop：模型决定是否调用工具，Runtime 执行工具，将结果回填给模型，直到模型给出最终答案或达到最大步数。

## 执行循环
1. System + User message
2. Model Gateway 请求
3. 若无 tool_calls，结束
4. 解析 function name / JSON arguments
5. Tool Registry 查找工具
6. 高风险工具进入 Approval Gate
7. 执行工具并记录 audit/event
8. tool result 回填模型
9. 重复直到完成或达到 AGENT_MAX_STEPS

## 安全边界
- 工具参数必须 JSON 对象
- 未注册工具拒绝执行
- 每次工具执行有超时
- 高风险工具不得绕过 Approval Gate
- 模型调用和工具结果写入任务事件流，但不记录凭据
