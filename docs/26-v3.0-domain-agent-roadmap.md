# V3.0 Domain Agent Roadmap

The first release establishes installable domain packs. Next iterations should replace placeholder metadata with real MCP servers and tool contracts.

Priority adapters:
1. Project: MPP import/export, Gantt, schedule variance, risk register.
2. BIM: IFC/Revit extraction, model QA, quantities, clash-review workflows.
3. Water: SCADA read-only telemetry, water-quality analysis, aeration optimization recommendations.
4. IoT: MQTT device registry, point cache, alarms, timeseries analysis and approved control workflows.

All write/control operations remain approval-gated and audited.
