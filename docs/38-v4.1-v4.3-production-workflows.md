# V4.1-V4.3 生产级 Agentic Workflow

## V4.1
Workflow 状态持久化、恢复、取消、重试、attempts/max_attempts，并与 PostgreSQL/现有任务体系共存。

## V4.2
加入企业业务写回边界：Project Gantt change-set、BIM Issue、IoT 工单、SCADA 控制 proposal。写操作默认 dry-run 或 approval required，避免模型直接获得生产控制权限。

## V4.3
Workflow Designer Schema：节点、依赖、循环检测、模板、验证 API。Vue/Electron 可直接消费该 schema 实现拖拽设计器。
