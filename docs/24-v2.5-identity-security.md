# V2.5 Identity and Security

- local JWT access token flow for development
- Bearer principal extraction
- tenant + role permission checks for management APIs
- admin management permission is required for Agent catalog mutations
- OIDC configuration fields are reserved for production identity integration

Production hardening: OIDC discovery/JWKS verification, refresh-token rotation, secret manager/KMS, CSRF/CORS policy, API-key hashing, per-tool policies, data retention, encryption, and immutable audit storage.
