# V5.0 Enterprise Agent OS

V5.0 consolidates Agent Studio, Skill/MCP/Workflow/Knowledge management, Marketplace, security, observability and enterprise domain packs behind one console.

## Product surfaces
- Agent Studio
- Workflow Studio
- Skill Studio
- MCP/Connector Studio
- Knowledge Studio
- Marketplace
- Approval Center
- Audit & Observability

## Runtime contract
Every executable action resolves through Tenant -> Principal -> RBAC -> Policy -> Approval (when required) -> Tool/MCP -> Audit.

## First-class domain packs
Project/MPP, BIM/IFC/Revit, Water/SCADA, IoT/MQTT/TDengine.
