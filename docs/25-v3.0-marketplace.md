# V3.0 Enterprise Agent Marketplace

V3.0 converts YoungAgent from a generic Agent runtime into an extensible enterprise Agent platform.

## Core
- Marketplace pack manifest and tenant-scoped installation
- Domain packs for Project, BIM, Water, and IoT/SCADA
- Unified Agent/Skill/MCP/Tool boundary
- Permission metadata and approval policy boundary

## Pack lifecycle
`discover -> inspect -> install -> enable -> execute -> audit -> upgrade -> rollback`

## Domain packs
- `youngagent.project`: project planning, MPP/Gantt, schedule/risk/document assistance
- `youngagent.bim`: BIM model/component/quantity/design-review assistance
- `youngagent.water`: wastewater operations, water quality, aeration/MPC and SCADA analysis
- `youngagent.iot`: MQTT, device points, alarms, telemetry and automation/O&M analysis

## Security rules
Marketplace installation is tenant-scoped. Domain packs declare permissions; execution must still pass runtime RBAC and Approval Gate checks. Control actions are never implicitly enabled by a pack.
