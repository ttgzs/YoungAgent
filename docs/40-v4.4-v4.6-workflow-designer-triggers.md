# V4.4-V4.6 Workflow Designer / Trigger / Event Bus

## V4.4
Vue 3 workflow designer with node editing, dependency selection, approval flags, DAG validation and persistence.

## V4.5
Workflow execution keeps a single business-action boundary. Domain handlers/connectors are the write-back boundary; sensitive operations remain behind RBAC + Approval + Audit.

## V4.6
Trigger registry supports interval, event and webhook trigger types. Interval triggers run through the background scheduler; event triggers can be fired through `/api/v1/events/publish`. Trigger execution loads durable workflow state and persists the resulting state.

## Production hardening
The in-process scheduler is the baseline implementation. For HA production, replace it with Redis Streams/Celery/Temporal/Quartz/Kubernetes CronJobs and persist trigger definitions in PostgreSQL.
