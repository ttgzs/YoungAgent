# V2.3 Enterprise RAG

- document -> chunk -> embedding -> persistent chunk index -> semantic retrieval
- OpenAI-compatible `/embeddings` supported through `EMBEDDING_MODEL`
- deterministic local hashing embedding fallback for development
- tenant isolation on knowledge chunks
- retrieval API: `/api/v1/knowledge/semantic-search`

Production recommendation: PostgreSQL + pgvector or dedicated vector DB, reranker, ACL-aware retrieval, parser/OCR pipeline, object storage and document versioning.
